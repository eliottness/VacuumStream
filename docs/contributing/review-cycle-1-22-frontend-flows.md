# Cycles 1-22 review: frontend QA flows

[Contribution guidelines](../../CONTRIBUTING.md) · [Development](development.md) · [Architecture](architecture.md)

These flows were queued by the per-cycle and cross-cutting review lanes covering main `4710cc9..a2fe642`.
Each flow is a controller-only journey with one binary observable.
The Scope column says where it can be executed.
The Verdict and Artifact columns are filled in by the reviewer who runs the flow.

## Scope classes

- `LOCAL-GUEST`: runs on the desktop build in guest mode with keyboard-synthesized controller input - no Twitch account, no physical gamepad.
- `NEEDS-AUTH`: requires a signed-in Twitch account; out of scope for this review because changing or re-authorizing the project's Twitch token is forbidden.
- `NEEDS-HARDWARE`: requires a physical gamepad or the HTPC; out of scope for a desktop run.

## Execution results (2026-09-22)

Six rows the lanes had filed as NEEDS-HARDWARE needed only local fixture data or an extra desktop
launch (F-cycle-11-7, F-cycle-16-4, F-cycle-14-1, F-cycle-14-3, F-cycle-14-4, F-cycle-20-2); they
were reclassified LOCAL-GUEST and executed. Four past-broadcast rows had been blocked on a
supposed sign-in requirement; the resume route needs no account, so they were executed against a
real public VOD seeded as a bookmark.

Executed by the review orchestrator against the real Electron renderer: the app was built from
main at `a2fe642` (`out/` built 2026-09-22 08:43 from the same tree) and launched under WSLg on
`DISPLAY=:0` with `--remote-debugging-port=9333` and throwaway profiles (`/tmp/vs-qa-profile`, then `/tmp/vs-qa-profile2` for the seeded-fixture rows).
Input was synthesized as real key events over the Chrome DevTools Protocol
(`Input.dispatchKeyEvent`), so every journey below used arrows, Enter, Escape and typing only -
no pointer, no direct `element.focus()`. Screenshots are `Page.captureScreenshot` PNGs; the viewport is 1920x1080 unless the row's
observation names another size, and each row that asserts a size reports the measured viewport. Artifacts live under `.omo/review/qa/` (git-ignored).

Five LOCAL-GUEST rows remain BLOCKED, each on an environment limit rather than an account: the
native chat-input transport refuses unless the app window holds OS focus, which WSLg here cannot
grant (F-xc-docs-4, F-xc-security-2, F-cycle-07-4, F-cycle-08-3), and a device challenge has to
expire on Twitch's own clock (F-cycle-19-6). Everything else was executed: bookmarks and
favourites were seeded as JSON into a throwaway profile, and the past-broadcast rows ran against a
real public Twitch VOD (id 2877678922, 47:59:57) seeded as a bookmark - the resume route opens a
recording without an account. One row FAILS (F-cycle-07-6, filed as `D-manual-qa-5`) and the
PARTIAL rows each name the half of their predicate that could not be produced here.

Six findings came out of executing these flows. Four are filed in the
[defect ledger](review-cycle-1-22-defects.md) as `D-manual-qa-2`, `D-manual-qa-3`,
`D-manual-qa-5` and `D-manual-qa-6`; two more (`D-manual-qa-1`, `D-manual-qa-4`) were
withdrawn after the first gate review showed they describe intended behaviour, and they are kept
in that ledger's "Withdrawn findings" section.
